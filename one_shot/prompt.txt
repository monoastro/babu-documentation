# Document Digitization Rules
## Nepali Government Documents → English HTML

> Derived from the translated HTML files in `translated/` (bimal/, ganesh_mina/, and root-level files).
> These rules govern how scanned or source Nepali documents are converted into structured, editable English HTML pages that faithfully preserve layout, size, and visual hierarchy.

---

## 1. General Principles

### 1.1 Language Translation
- **All text is translated from Nepali (Devanagari script) to English.**
- Retain the original meaning and official terminology; do not paraphrase.
- Government office names, legal act references, and role titles must use their standard English equivalents (e.g., "Chief District Officer", "Ministry of Home Affairs", "Nepal Citizenship Act, 2063").
- Personal names are **transliterated** (not translated) from Nepali to English Roman script (e.g., `Ganesh Kumar Kandangwa`, `Sita Devi Rayamajhi`).
- Place names are **transliterated** (e.g., `Tehrathum`, `Udayapur`, `Topgachhi`).
- Field labels (e.g., `Full Name:`, `Date of Birth:`, `Ward No.:`) are fully translated to English.

### 1.2 Faithful Layout Reproduction
- The HTML output must visually replicate the source document's layout: absolute or relative positioning, fixed `width`/`height` dimensions in `px` (or `mm` for A4 documents), and matching font sizes.
- Do not reflow or restructure sections unless necessary to fit a target page size.
- Documents that use a fixed landscape canvas (e.g., citizenship cards at 1200x780 px) or portrait A4 canvas (794x1123 px) must preserve those dimensions.

### 1.3 Typography
- Default font: `"Times New Roman", Times, serif` for all formal government documents.
- Exception: documents that use Devanagari numerals or mixed-script content may also include `"Noto Sans Devanagari"` as the first font in the stack.
- Font sizes must match the visual weight of the source: headings ~22–28 px, body text ~13–20 px, footnotes/notes ~11–13 px.

### 1.4 Colour & Background
- Background: `#ffffff` (white) throughout.
- Text: `#000000` (black).
- Borders: `#000000` or `2px solid #000000` for document borders; `1px solid #000000` for inner section borders.
- No coloured backgrounds on field cells unless the source document uses them.
- Watermark text (e.g., repeating "INLAND REVENUE DEPARTMENT") is reproduced using a CSS `::before` pseudo-element with `opacity: 0.075` and an appropriate pale colour (e.g., `#b9a000`).

## 2. Visual Placeholder Rules

### 2.1 Photographs
Every **photograph** area on the original document is replaced with a **bordered box of the same width x height** containing a short text description. No actual image is embedded.

**Pattern:**
```html
<div style="
  font-size: 14px;
  text-align: center;
  width: {W}px;
  height: {H}px;
  border: 2px solid #000000;
  display: flex;
  position: absolute;
  top: {T}px; left: {L}px;
  justify-content: center;
  align-items: center;
">
  <span>Photograph Sd.</span>
</div>
```

- Label text: `"Photograph Sd."` (citizenship, land certificate) or `"Photograph(Sd.)"` (PAN card).
- Size must match the original photo area exactly (e.g., 260x260 px for a citizenship photo, 134x165 px for a PAN card photo, 110x155 px for a land certificate).
- Positioning (`top`, `left`, `right`) must be preserved from the source layout.

### 2.2 Government Emblems / Coat of Arms
The **Coat of Arms of Nepal** (or government logo) is replaced with a **square or near-square bordered box** of matching dimensions containing a descriptive label.

**Typical sizes observed:**

| Document Type | Width x Height | Shape | Label |
|---|---|---|---|
| Citizenship Certificate | 120x120 px | Square | `"Coat of Arms of Nepal"` |
| PAN Certificate (detailed) | 90x90 px | Square | `"Government of Nepal logo"` |
| PAN Certificate (simple) | 115x115 px | Square | `"Government emblem"` |
| Tax Clearance Certificate | 82x82 px | Circular (`border-radius: 50%`) | `"Coat of Arms of Nepal"` |
| Land Ownership Certificate | 110x90 px | Rectangle | `"Coat of Arms of Nepal"` (two-line `<span>`) |

**Circular emblem pattern (Tax Clearance):**
```html
<div style="
  font-size: 13px;
  text-align: center;
  box-sizing: border-box;
  width: 82px; height: 82px;
  padding: 4px;
  border: 2px solid #000000;
  border-radius: 50%;
  display: flex; overflow: hidden;
  justify-content: center; align-items: center;
">
  <span>Coat of Arms of Nepal</span>
</div>
```

### 2.3 Official Seals (Round / Office Stamps)
**Round office seals** and **circular stamps** are replaced with a bordered box (square or circular) containing a text description.

**Common patterns:**
- **Citizenship (round seal, top right):** 120x120 px square box → `"Round Office Seal"`
- **PAN Certificate (top-right circular seal):** 85x85 px circle (`border-radius: 50%`) → multi-line text `"Government / Office / Seal"`
- **PAN Certificate (taxpayer/school stamp):** circular stamp in signature area → 95x50 px box or 110x110 px circle → label `"[Office Name] Stamp"` with a CSS double-ring created using `::before`
- **Tax Clearance QR Code area:** 62x62 px square → `"QR Code"`

**Double-ring stamp pattern:**
```html
<div class="shree-stars-stamp" style="
  width: 110px; height: 110px;
  border: 2px solid #000;
  border-radius: 50%;
  position: relative;
">
  <!-- inner ring via ::before -->
  <span>[Office Name]</span>
</div>
```

### 2.4 Thumb Impressions / Fingerprints
Thumb impression areas are replaced with a **dashed-border box** of matching size with a short label.

```html
<div style="
  font-size: 13px;
  text-align: center;
  box-sizing: border-box;
  width: 165px; height: 165px;
  padding: 4px;
  border: 2px dashed #000000;
  display: flex; overflow: hidden;
  justify-content: center; align-items: center;
">
  <span>Provided</span>
</div>
```

- Dashed border (`border: 2px dashed`) distinguishes thumb impressions from solid-border photo boxes.
- Label: `"Provided"` (if impression was present), or `"Right"` / `"Left"` inside dividers in table-style layouts (Land Ownership Certificate).

### 2.5 Signature Boxes
**Signature areas** (for officers, taxpayers, certificate holders) are replaced with a **bordered rectangle** containing a label.

```html
<div class="signature-box" style="
  width: 220px; height: 75px;
  border: 1px solid #000;
  display: flex;
  align-items: center; justify-content: center;
  text-align: center;
  font-size: 14px; font-weight: bold;
">
  [Role] Signature
</div>
```

- When a signature is inline (short reference), use the abbreviation `"Sd."`.

### 2.6 QR Codes
QR code areas are replaced with a **square bordered box** labelled `"QR Code"`.

```html
<div style="
  font-size: 13px;
  text-align: center;
  box-sizing: border-box;
  width: 62px; height: 62px;
  padding: 4px;
  border: 2px solid #000000;
  display: flex; overflow: hidden;
  justify-content: center; align-items: center;
">
  <span>QR Code</span>
</div>
```

## 3. Editable Fields

### 3.1 `contenteditable` Attribute
All data fields that could vary per individual must be marked `contenteditable="true"` with a `data-field` attribute identifying the field name. This enables in-browser editing without code changes.

```html
<div contenteditable="true" data-field="full_name">Ganesh Kumar Kandangwa</div>
```

### 3.2 Field Naming Convention
`data-field` values use `snake_case`. Repeated structures (e.g., multiple land plots) use dot-notation: `plots.0.plot_no`, `plots.1.vdc`, `income_items.0.total_income`.

**Common field names observed across document types:**

| Field | `data-field` value |
|---|---|
| Citizenship number | `citizenship_no` |
| Full name | `full_name` |
| Gender / Sex | `gender` / `sex` |
| Date of birth year/month/day | `dob_year`, `dob_month`, `dob_day` |
| Birth district | `birth_district` |
| Birth municipality/VDC | `birth_rm_mn` |
| Birth ward | `birth_ward` / `birth_ward_no` |
| Permanent address district | `perm_district` |
| Permanent address municipality | `perm_municipality` |
| Permanent ward | `perm_ward` / `perm_ward_no` |
| Father's name | `father_name` |
| Father's citizenship no. | `father_citizenship_no` |
| Father's address | `father_address` |
| Father's citizenship type | `father_na_ki` |
| Mother's name | `mother_name` |
| Mother's citizenship no. | `mother_citizenship_no` |
| Spouse's name | `spouse_name` |
| Citizenship type | `citizenship_type` |
| Issue date (BS) | `issue_date_bs` |
| Taxpayer name | `taxpayer_name` |
| Business name | `business_name` |
| PAN number | `pan_no` |
| Inland Revenue Office | `inland_revenue_office` |
| Tax clearance number | `tax_clearance_no` |
| Land owner name | `owner_name` |
| Certificate number | `certificate_no` |

### 3.3 Non-Editable Display Fields
Static structural text (headers, department names, legal references, instructions) is **not** marked `contenteditable`. These are rendered as plain `<h1>`–`<h4>`, `<span>`, or `<div>` elements.

### 3.4 Hover / Focus Styles
All `contenteditable` fields must have interactive outline styles:
```css
[contenteditable]:hover { outline: 2px dashed #000000; cursor: text; }
[contenteditable]:focus  { outline: 2px solid #000000; background: #ffffff; }
```

## 5. Date Format Rules

### 5.1 Bikram Sambat (BS) Dates
Nepali calendar dates (BS / Vikram Sambat) are preserved as-is when they are the original document's date system. They are formatted as `YYYY-MM-DD` or `YYYY.MM.DD` in text, or split into separate Day / Month / Year cells in a table.

### 5.2 Anno Domini (AD) Dates
When the document also states a date in AD (Gregorian), it is translated/computed and shown alongside the BS date, labeled explicitly: `"Year: 1961"`, `"Month: JUL"`, `"Day: 02"` (citizenship back), or `"2026.07.26 AD"` (tax clearance).

### 5.3 Date Label Convention
- In table cells: separate `Day` | `Month` | `Year` column headers
- In text fields: prefix labels — `"Year: YYYY"`, `"Month: MM"`, `"Day: DD"`
- In narrative text: `"YYYY.MM.DD AD"` or `"YYYY-MM-DD"`

## 7. Header Structure Convention

For all formal government documents, the header follows this hierarchy (centered):

```
[Government Emblem / Coat of Arms]   [Title Lines]   [Office Seal]
                  Government of Nepal
                  Ministry of [X]
                  Department of [X]  (if applicable)
                  [Issuing Office Name]
                  [Certificate/Document Title]
```

- Headings use `<h1>` through `<h4>` tags (or `<span>` elements with matching font-weight/size) — each level decreasing in authority.
- All heading margin is set to `0` to allow tight line-height control.
- Emblem is positioned absolutely to the left; office seal to the right; title block is centered in between.

## 8. Print & Media Rules

All documents include:
```css
@media print {
  body { background: #ffffff !important; margin: 0 !important; }
  .page {
    margin: 0 !important;
    box-shadow: none !important;
    border: 2px solid #000000 !important;
    page-break-after: always;
  }
  .no-print { display: none !important; }
}
```

A4 documents additionally set:
```css
@page { size: A4 portrait; margin: 0; }
```
and in the print media block:
```css
.page { width: 210mm; height: 297mm; }
```
